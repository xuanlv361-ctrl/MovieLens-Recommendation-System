# Generated Figures

All figures are generated by `notebooks/01_movielens_recommendation.ipynb`.

## EDA

- `rating_distribution.png` - Distribution of 1-5 ratings.
- `ratings_per_user.png` - Number of ratings contributed by each user.
- `ratings_per_movie.png` - Number of ratings received by each movie.
- `genre_counts.png` - Number of movies in each MovieLens genre.

## Model Comparison

- `model_comparison.png` - RMSE and MAE comparison across rating-prediction models.
- `pred_vs_actual_*.png` - Predicted vs. actual rating scatter plots.
- `residuals_*.png` - Prediction residual distributions.
- `error_by_rating_item_cf.png` - ItemCF error by actual rating level.

## Top-N Ranking

- `topn_metrics_comparison.png` - Precision@10, Recall@10, HitRate@10, and NDCG@10 by model.
- `most_popular_recommendation_frequency.png` - Frequency distribution of movies recommended by the Most Popular baseline.

## Diagnostic Analysis

- `user_tier_rmse.png` - RMSE by user activity tier.
- `item_tier_rmse.png` - RMSE by movie popularity tier.
- `genre_rmse.png` - Per-genre RMSE breakdown for the selected diagnostic model.

## Hyperparameter Sensitivity

- `cf_k_sensitivity.png` - UserCF and ItemCF RMSE as `K_NEIGHBORS` changes.
- `svd_components_sensitivity.png` - SVD RMSE/MAE as `n_components` changes.
- `bias_regularization_sensitivity.png` - Bias baseline train/test RMSE across regularization strengths.

## Advanced Analysis

- `learning_curve.png` - Train/test RMSE as the training subset grows.
- `diversity_novelty.png` - Genre diversity and popularity-based novelty of Top-N recommendations.
